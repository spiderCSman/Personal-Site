    How it's built
    • State lives in one array. Every change writes to localStorage and re-renders from that single source of truth — the DOM is never read back.
    • One listener for the whole list. Event delegation on the <ul> rather than a listener per row, so adding a task costs nothing.
    • Native drag and drop for reordering, with a keyboard fallback — focus a task and press Alt + ↑ / ↓.
    • Degrades safely. If localStorage is blocked or full, it catches and keeps working in memory instead of throwing.
    • Accessible. Fully keyboard operable, live-region counter, and it respects prefers-reduced-motion.
